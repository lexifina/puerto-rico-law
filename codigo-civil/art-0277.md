# Artículo 277. Forma impuesta, libre o convenida.
Cuando la ley no designa una forma para la realización de un negocio jurídico, se puede utilizar aquella que se considere conveniente.
Cuando las partes han convenido que determinado negocio jurídico habrá de formalizarse de determinada manera, el negocio jurídico no tiene validez si se realiza de forma distinta.
Si la ley impone una forma determinada para la validez de un negocio jurídico, la inobservancia produce la nulidad.
