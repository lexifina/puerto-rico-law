# Artículo 795. Acción declaratoria de la usucapión.
Una vez transcurre el plazo para que se consume la usucapión, el adquirente puede entablar acción para que se le declare titular del derecho usucapido. La sentencia favorable es título para la inscripción del derecho en el registro respectivo y para cancelar el asiento a favor del antiguo titular.
